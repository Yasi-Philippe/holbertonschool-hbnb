Create New User

Quick notes
  • New users can log in immediately after creation.
  • Admin rights cannot be set here — edit the DB directly.
  • Email addresses must be unique across all accounts.

Create New Amenity

Quick notes
  • Amenity names are shared across all places.
  • Keep names short — one or two words is ideal.
  • Duplicates are case-sensitive, so avoid near-copies.
  • Deleting an amenity removes it from every place that has it.

Create New Place

Quick notes
  • New places are owned by the currently logged-in admin.
  • Latitude: –90 to 90  ·  Longitude: –180 to 180.
  • Price is in USD per night.
